## Track 4 — Phase 2 Foundations (fully unblocked; synthetic data only where stated)
Phase 2 scope: computational fluid dynamics (CFD), finite-element blood flow modeling,
and live contrast transport predictions. Governing dynamics: contrast as a passive or
semi-passive scalar governed by advection-diffusion:

    ∂C/∂t + u · ∇C = D ∇²C

Where C = local contrast concentration, u = blood velocity, D = molecular diffusion. At
typical arterial velocities, advection heavily dominates diffusion. Vascular blood flow
acts as the moving carrier fluid.

Work the four Acceleration Pathways, prioritized by current unblocked status:
1. Surrogate AI Operators (START HERE — explicitly synthetic-data-driven): train
   physics-informed neural operators (e.g., GINO, Transolver) on synthetic runs to infer
   flow fields and pressure drops in real time. No patient data or gated downloads
   required. Build training infra and generate synthetic run corpora.
2. 0D/1D Reduced-Order Networks: abstract vessels into 1D centerline networks using
   `svZeroDSolver` or `openBF`; prototype on the already-processed vessel trees from the
   5 real cases to compute branch transit times and arrival curves in milliseconds.
3. Decoupled Steady-State Transport: prototype computing the periodic velocity field u
   once over the cardiac cycle so that only the scalar transport field C is recalculated
   when injection parameters change. Can be prototyped against the advection-diffusion
   equation above.
4. GPU-Accelerated Solvers (evaluation only at this stage): benchmark/compare Lattice
   Boltzmann Method (LBM) architectures — OpenLB, HARVEY, FluidX3D — for parallelized
   fluid sweeps on cloud GPUs. Produce a selection recommendation.
