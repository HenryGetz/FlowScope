# License Audit — FlowScope

**Track 5 deliverable.** Date: 2026-09-23. Scope: every dataset touched by the project, plus the
TotalSegmentator segmentation task actually invoked, plus an informational tooling note. All license
evidence cited below is already captured in this repository (`data/manifest.json`, `tools/*`) or at
stable upstream URLs. One informational lookup (svZeroDSolver upstream license) was made via the
GitHub API and is marked as such.

This audit records facts and implications. **It does not grant any rights and does not resolve the
commercial-use question** — see "Brief discrepancy and human compliance decision" below.

**Allowed / forbidden (CC BY-NC-ND 4.0 terms):**

- **Use**: allowed for **non-commercial** purposes only ("NonCommercial" = not primarily intended for or
  directed toward commercial advantage or monetary compensation).
- **Modification / derivatives**: you MAY produce adapted material privately, but **NoDerivatives**
  forbids **sharing/redistributing** adapted material (meshes, edited masks, derived renderings,
  fine-tuned models, etc.) except under the license's narrow personal-use carve-outs.
- **Redistribution**: verbatim copies allowed for non-commercial use with attribution; adapted
  material may not be distributed.
- **Attribution**: required ("BY") with license link and indication of changes.

**Implication for COMMERCIAL CLINICAL USE alongside BMT/ACIST hardware (ACIST Pro/CVi, HDi/Kodama HD
IVUS, RXi/Navvus, EmpowerCTA+/EmpowerMR — all commercial products):**
Any clinical or product-integration use in connection with those commercial devices is a
**commercial use** and is **outside the license grant entirely** — not merely an attribution problem.
Furthermore, the derived geometry our pipeline produces (STL meshes, GLB renderings, surrogate-model
weights trained on these fields) plausibly constitutes "Adapted Material", which may not even be
shared in a research context, let alone shipped with a product. **Compliance risk: highest of the
three datasets.**

## 2. Brief discrepancy — flagged

The project brief claims the data/tooling sit under **"open Apache 2.0 / CC BY 4.0."** The evidence
does **not** support that claim for the primary assets:

| Brief claim | Actual finding |
|---|---|
| "open Apache 2.0" (for TotalSegmentator) | True only for the **engine**. The `heartchambers_highres` **task** — the component we actually need for heart chambers — requires a **separate license** (free non-commercial `aca_...`, or paid commercial). |
| "CC BY 4.0" (for the imaging data) | True only for **TotalSegmentator CT dataset v2** (§1.2). The brief's primary set (HF `AI-CVM/Cardiac-CT`, §1.1) is **CC-BY-NC-ND-4.0**, and the acquired base ImageCAS (§1.3) is **CC BY-NC 4.0** — both carry a **NonCommercial** clause, and the primary set additionally carries **NoDerivatives**. |
| (implicit) dataset name "TotalSegmentator CT High-Res" | **Nonexistent**; actual set is TotalSegmentator CT dataset v2 (§1.2). |

So the brief's "open Apache 2.0 / CC BY 4.0" characterization is accurate for at most one of the four
licensed components and materially wrong for the two ImageCAS sources and the heart-chambers task.
As recorded in `data/manifest.json` → `blocked`: the brief's primary set and the acquired Kaggle set
"are different licenses" and only CC BY-NC 4.0 governs the acquired Kaggle data.

## 3. Human compliance decision — hand-off (unresolved, deliberately)

**Resolution requires a HUMAN COMPLIANCE DECISION.** This audit does not pick an option. The decision
options are:

1. **Negotiate commercial licenses** with the AI-CVM authors (HF `AI-CVM/Cardiac-CT` dataset terms /
   https://github.com/AI-in-Cardiovascular-Medicine/CCT-FM) and with the TotalSegmentator authors
   (jakob.wasserthal@usb.ch) — covering both the dataset terms and the `heartchambers_highres` task
   for commercial clinical use alongside BMT/ACIST hardware.
2. **Restrict use to research-only demoing** — keep every demo, publication, and derived artifact
   non-commercial, with full attribution and no redistribution of adapted material from the
   CC-BY-NC-ND source; no commercial clinical claims whatsoever.
3. **Source replacement data** — obtain anatomy data under licenses compatible with commercial
   clinical use (e.g., CC BY 4.0 / CC0 / institutionally licensed data) and rebuild the geometry
   corpus.

Interim posture until a human decides: treat all ImageCAS-derived and heartchambers-derived assets as
**non-commercial research-only**, keep attribution with every artifact, and do not distribute adapted
material from the CC-BY-NC-ND set. The TotalSegmentator CT dataset v2 (CC BY 4.0) may be used
commercially with attribution. The TotalSegmentator engine (Apache 2.0) may be used commercially.
