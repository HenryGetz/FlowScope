# Track 4.3 - Decoupled vs Coupled Contrast-Transport Benchmark

Generated by `phase2/transport/compare.py` v1.0.0 on 2026-09-23T15:27:20 (grid 48^3, HR 72 bpm, a = 0.2).

## Governing equation

Blood-borne contrast transport (advection-dominated at arterial velocities):

    dC/dt + u . grad(C) = D * laplacian(C)

## Discretization

```
Scalar transport (finite volume, cell centred, conservative flux form):
  advection : 2nd-order upwind face reconstruction
              u_f > 0: C_f = C_L + 1/2 (C_L - C_LL);  u_f < 0: C_f = C_R - 1/2 (C_RR - C_R)
              (1st-order upwind fallback where the 2nd upwind donor cell is not fluid)
  diffusion : 2nd-order central face gradients, zero flux across lumen walls
  time      : forward Euler with CFL-controlled substepping shared by both arms,
              dt = min( CFL / sum_d max|u_d| (1+a) / h_d , 0.5 / (2 D sum_d 1/h_d^2) )
  boundary  : inlet Dirichlet bolus C_in(t) (flow-diluted square bolus, tanh edges),
              outlet advective outflow (zero-gradient ghosts).
Velocity field (computed once per anatomy in the decoupled arm, per injection in
the coupled arm): steady Stokes -mu grad^2 u + grad p = f, div u = 0 on the
staggered MAC grid of the synthetic tubular domain (streamwise periodic,
no-slip staircase lumen walls, constant body force calibrated to the target
flow rate); saddle system reduced to its SPD Schur complement and solved with
preconditioned CG.  Cardiac periodicity is imposed analytically:
  u(x,t) = u_bar(x) (1 + a sin(omega t)),  a = 0.2, HR = 72 bpm (omega = 2 pi HR/60).
```

## Benchmark protocol

* **DECOUPLED**: steady velocity solve once (cached), scalar transport re-solved per injection (arbitrary bolus volume / rate / diffusivity).
* **COUPLED**: steady velocity solve **and** scalar transport re-solved per injection, at the injection's total flow rate Q_blood + Q_inj (the injector's 1-5 mL/s is not negligible against ~15 mL/s of blood flow).
* Both arms share the identical scalar discretization AND the identical time-step grid within a variant (dt = min over both arms' CFL bounds) so that discretization noise cancels in the fidelity metric.
* `t_coupled = t_velocity + t_transport`, `t_decoupled = t_transport` per injection; the one-time cache build is counted once in `t_decoupled_total_s`.
* `outlet_curve_rel_error_max` = max_t |C_dec - C_coup| / max_t C_coup over the recorded window (peak-normalised max deviation of the outlet arrival curve).

(sparse LU + CG) scales superlinearly in N while the transport re-solve scales
roughly linearly.  The full 27-variant benchmark above runs at grid 48^3 (the
lower end of the specified 48-64 range) to keep the two-arm sweep tractable.

## Notes & interpretation

* The coupled arm re-solves the steady flow per injection because the power injector materially changes the domain flow rate (Q_blood = 15.08 mL/s vs Q_inj = 1-5 mL/s). Under the strict one-way reading of the decoupling (velocity independent of injection), both arms run the identical transport discretization on identical time-step grids and the arrival curves agree to round-off; the reported error quantifies the frozen-velocity (frozen-flow-rate) approximation instead.
* Stokes linearity finding: the per-injection velocity solve collapses to an exact analytic rescaling u(Q) = (Q/Q_blood) u_blood (verified to 2.8e-15). A production decoupled predictor should therefore cache u_blood and apply the known flow-rate scaling, recovering coupled fidelity at decoupled cost; the strict frozen-u arm benchmarked here is the conservative case. (In nonlinear/in-vivo coupled CFD - non-Newtonian viscosity, fluid-structure coupling - the per-injection flow re-solve does not collapse this way.)
* The steady velocity model is linear Stokes (inertia neglected); at arterial Reynolds numbers O(10^2-10^3) in a mild stenosis this is the standard first-order prototype choice. Both arms use the same velocity model, so the benchmark comparison is unaffected.
* Arrival-curve windows are min(T_bolus + 1.5 s, 4.0 s): long injections (T_bolus up to 20 s) are recorded over their arrival transient + early plateau in both arms (identical truncation).
* t_decoupled_total_s includes the one-time cache build (steady velocity solve); per-injection decoupled cost is the transport re-solve alone.
